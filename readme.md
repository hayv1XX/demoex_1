## Стек
- Node.js + Express
- PostgreSQL
- EJS (шаблоны)

## Запуск

1. Клонировать репозиторий
2. `npm install`
3. Создать БД и выполнить `init_db.sql`
4. Создать `.env` со своими параметрами БД (пример в `.env.example`)
5. `node app.js`
6. Открыть http://localhost:3000
